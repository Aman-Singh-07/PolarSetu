# License Proposal: MIT License

## Recommendation
For a Smart India Hackathon (SIH) project with multiple contributors, the **MIT License** is highly recommended as a permissive open-source license. It allows evaluators, researchers, and other developers to safely run, inspect, and build upon the software without unnecessary legal friction.

## Important Note on Third-Party Assets
The MIT License would only apply to the **source code** (React, Go, CSS, SQL migrations, etc.) written by the AICYGRAM team.

It **does not** automatically grant distribution rights or ownership over third-party assets such as:
- External educational videos (e.g., U.S. National Science Foundation).
- Official logos (e.g., NCPOR, MoES).
- Externally sourced expedition photographs or maps.

Please see `IMAGE_SOURCES.md` and `VIDEO_SOURCES.md` for proper attribution of those materials.

## Next Steps
If all repository contributors and rightsholders agree to open-source the codebase under these terms:

1. Create a new file named exactly `LICENSE` in the root of the repository.
2. Copy the standard MIT License text below into the file.
3. Replace `[Year]` with the current year (e.g., 2026).
4. Replace `[Full Name or Organization]` with the agreed copyright holder(s) (e.g., The AICYGRAM Team).
5. Delete this proposal file.
